# AI management capstone

## Objectives

- **Big data train.md**: EDA narrative on Dallas crime data — loading, cleaning context, univariate and multivariate views, and suggestions for predictive or dashboard-style follow-ups.
- - **Capstone notebook**: Work on actual data and real setting, using tabular chart, MV metadata and engineered audio-features (e.g. MFCC summaries, duration, chart dates) for analysis and modeling.
